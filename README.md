# 🏏 IPL Analytics Intelligence Platform

> End-to-end IPL Data Analytics, Machine Learning, and Business Intelligence platform built using Python, Streamlit, Plotly, and Power BI.


---

# 📌 Project Overview

The **IPL Analytics Intelligence Platform** is a complete sports analytics project that analyzes Indian Premier League (IPL) data from **2008–2024**.

This project demonstrates:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning
- Interactive Dashboard Development
- Business Intelligence Reporting

The platform transforms raw IPL datasets into actionable insights using advanced analytics and visualization techniques.

## 🤖 Machine Learning
### Win Probability Prediction System

Implemented using:

```python
Logistic Regression
```

### Features Used
- Toss winner
- Toss decision
- Venue encoding

### Model Metrics

| Metric | Value |
|---|---|
| Accuracy | ~58–62% |
| ROC-AUC | ~0.60 |

---

# 🧠 Key Insights

- Mumbai Indians and Chennai Super Kings dominate historical win percentages.
- Teams choosing to field after winning the toss have a slightly higher win probability.
- Virat Kohli remains the all-time leading IPL run scorer.
- Lasith Malinga is among the top wicket takers with exceptional economy.
- Toss advantage alone is not enough for accurate match prediction, proving cricket's unpredictability.

# 📦 Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/RAMPELLY-NIKHIL/ipl-analytics-intelligence-platform.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd ipl-analytics-intelligence-platform
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Run Analysis Pipeline

```bash
python ipl_analysis.py
```

---

## 5️⃣ Launch Streamlit Dashboard

```bash
streamlit run app.py
```
