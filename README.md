# 🏏 IPL Analytics Intelligence Platform

> End-to-end Data Analytics, Machine Learning, and Business Intelligence platform analyzing 16 years of Indian Premier League (IPL) cricket data from 2008 to 2024.

![IPL Dashboard](ipl_eda_dashboard.png)

---

# 🚀 Project Overview

The IPL Analytics Intelligence Platform is a complete cricket analytics solution built using:

- Python
- Machine Learning
- Streamlit
- Power BI
- Plotly
- Pandas
- scikit-learn

This project transforms raw IPL match and ball-by-ball datasets into interactive dashboards, predictive insights, and business intelligence reports.

---

# 📊 Features

## ✅ Executive Dashboard
- Total matches analysis
- Venue intelligence
- Toss impact analysis
- Team performance metrics

## ✅ Batting Analytics
- Top run scorers
- Strike rate analysis
- Batting average insights
- Scatter plot comparisons

## ✅ Bowling Analytics
- Top wicket takers
- Economy rate analysis
- Bowling average metrics
- Performance leaderboards

## ✅ Team Intelligence
- Team win percentage
- Head-to-head analysis
- Toss-to-win conversion
- Season-wise performance

## ✅ Machine Learning
- Logistic Regression win prediction model
- Match win probability calculator
- Toss impact prediction
- Venue-based prediction analysis

## ✅ Interactive Streamlit App
- Fully interactive dashboard
- Dynamic filtering
- Real-time analytics visualizations
- Modern dark UI
